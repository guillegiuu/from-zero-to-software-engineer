# 🧠 Challenge 01: Not Sum To Ten

## 📌 Problema

Dado dos números (`num1` y `num2`), determinar si su suma **NO es igual a 10**.

---

## 🔍 Lógica

1. Calcular la suma:  
   `num1 + num2`

2. Comparar con 10 usando:
   `!=`

3. Guardar el resultado en una variable booleana

---

## 💡 Implementación

```python
if (num1 + num2) != 10:
    not_ten = True
else:
    not_ten = False
```
