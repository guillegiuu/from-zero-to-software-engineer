## 🧠 Concepto

El sistema binario utiliza solo dos valores: `0` y `1`.

## 🔑 Idea clave

Las computadoras trabajan con estados simples (encendido/apagado).

## 📌 Puntos importantes

- Base 2
- Representación interna de datos
- Cada posición es una potencia de 2

## 💡 Ejemplo

`1011` → 11 en decimal
