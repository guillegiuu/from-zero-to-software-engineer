## 🚀 Conceptos importantes

- `open()` abre archivos.
- `read()` lee contenido.
- `write()` escribe contenido.
- `"w"` reemplaza contenido.
- `"a"` agrega contenido al final.
- `with open()` es la forma recomendada.
- CSV guarda datos tabulares.
- JSON guarda datos estructurados.
