---

## 🧩 Conceptos clave

- Un diccionario guarda datos como **clave → valor**
- Las claves deben ser **únicas**
- Las claves deben ser **inmutables**
- Los valores pueden repetirse
- El acceso promedio es **O(1)**
- Son muy útiles para problemas de conteo y búsqueda rápida
