# 🌳 Q2 — DFS Tree (Path)

## 📌 Tema
DFS (Depth-First Search) en árbol

---

## ❌ Error
Confundir recorrido completo con camino (`path`)

---

## ✅ Corrección

Camino correcto:

// A → C → H → D → G

---

## 🧠 Clave

- DFS baja por una rama hasta el fondo
- `path` = camino actual
- No devuelve todos los nodos, solo el camino encontrado

---

## ⚠️ Trampa

Pensar que DFS devuelve todo el recorrido

👉 En este caso devuelve el primer camino válido

---

## 🎯 Regla

- DFS ≠ camino más corto  
- DFS = primer camino válido
